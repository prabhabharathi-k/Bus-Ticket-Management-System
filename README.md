# Bus Ticket Management System

## Project Overview
The Bus Ticket Management System is a desktop application developed using Python, MySQL, and Power BI. It helps manage bus ticket bookings, calculate fares, store passenger details, and analyze ticket data through interactive dashboards.

## Technologies Used
- Python
- MySQL
- Power BI

## Features
- Bus ticket booking
- Fare calculation
- Passenger record management
- Database integration with MySQL
- Interactive Power BI dashboard
- Revenue and route analysis

## Project Files
- Python source code
- SQL database script
- Power BI Dashboard (.pbix)
